# Banking UX Auditor

An India-focused UX and responsible-banking audit MVP.

## MVP
- Upload a banking flow video (UI shell; analysis integration comes next)
- Choose banking journey
- Banking-specific dark-pattern taxonomy
- RBI / CCPA / DPDP reference framework
- Evidence-oriented findings model
- UX transparency score model

## Product principle
The product distinguishes observed UX evidence, dark-pattern classification, and regulatory relevance. It is not a legal compliance certification tool.

## Stack
Next.js + TypeScript + Tailwind + shadcn/ui (planned baseline).
